na = 3, nb = 2, nc = 2,
a = [−1, 9, −2], b = [3, 4], c = [1, 2]
ia = 2, ib = 2 → совпадение
Изменим: a = [−1, 5, −2] (ia = 2), b = [1, 8] (ib = 2) → совпадение.
Для проверки «нет положительных» нужен единственный выбор:
a = [−1, −5, −2] (ia = 1), b = [1, 8] (ib = 2), c = [1, 2] (ic = 2) → совпадение b и c.
Возьмём b = [1, 8], c = [3, 2] (ic = 1) → выбор b, в b есть положительные
Особая ситуация «нет положительных» достижима: a = [−1, −5, −2] (ia = 1), b = [−3, −8] (ib = 1)? — совпадение.
Итог: na = 3, nb = 2, nc = 2,
a = [−1, −5, −2], b = [1, 8], c = [−3, −2] →
ia = 1, ib = 2, ic = 1 → выбор b, G = (1·8)^(1/2) ≈ 2.83.
Для случая «нет положительных»: a = [−1, −5, −2] (ia = 1), b = [3, −8] (ib = 1)? — совпадение;
b = [3, 8] (ib = 2) → выбор b, есть положительные.
Случай «нет положительных в выбранном»: a = [1, 2, 3] (ia = 3), b = [−1, −2] (ib = 1), c = [−3, −2] (ic = 1) →
выбор a, в a есть положительные. Чтобы получить «нет положительных»,
выбранный вектор должен состоять из неположительных,
но тогда его максимум отрицателен и индекс максимума может оказаться наибольшим:
a = [−1, −2] (ia = 1), b = [−3, −4] (ib = 1), c = [1, 2] (ic = 2) → выбор c, в c есть положительные.
Вариант: c = [−1, −2] нельзя — нужно ic = 3 при nb = 2... nc = 3: a = [−1, −2, −3] (ia = 1), b = [−4, −5] (ib = 1), c = [0, 0, −7] (ic = 3) →
выбор c, положительных нет → «В выбранном векторе нет положительных элементов»
